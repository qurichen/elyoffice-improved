# 第11轮工作收尾报告

日期：2026-10-23。本次工作已按用户要求结束，不再自动继续构建或审查。

这是第11轮结束时的历史快照；用户随后要求开始第12轮，其修正及新验证结果见
[第12轮验证记录](windows-validation-round12.md)。本文件不把旧失败记录改写成通过。

结论：保存安全、恢复文件处理和测试进程清理有实质改进，也取得了可复查的
通过记录；但最新原生恢复复验超时，表格和演示仍有待复验项。因此本轮保留为
实验性源码候选，不标记为正式发布或“长期稳定可用”。

## 本次主要改动

1. Windows另存默认后缀交给原生对话框处理；保留显式格式和覆盖确认，通用
   路径/目录选择不擅自推断后缀。
2. 恢复文件先认证、校验，再同目录原子发布；不覆盖已有目标，错误密钥、
   缺失源文件或写入失败不留下占位空文件，允许后续重试。
3. 恢复索引先检查路径、格式、编号和重复条目；只读取最新恢复点时，损坏的
   旧点不再阻挡最新点，最新点损坏仍明确报错。
4. 先让内核关闭文档句柄，再清理其所属临时子目录；阻止用户直接打开或另存
   到会被清除的工作目录，避免把个人文件当缓存处理。
5. 在内核子进程内启用随包英语词典，覆盖美式、英式、澳式、加拿大英语；
   不改系统环境，不宣称加入中文语法检查。
6. 三应用共用测试退出清理守卫，新增24轮连续编辑/保存/关闭检查；Windows
   测试运行器记录内存、子进程、退出码及跳过情况，并限制其自有进程树。
7. 修正部分Windows测试的换行、路径和菜单刷新假设；演示PDF页数改为项目内
   解析，避免依赖未安装工具而跳过。最后这些修改尚未完成运行复验。

本轮没有另造C++内核：继续使用此前的63补丁内核，也没有宣称达到微软Office
的排版和功能兼容程度。
