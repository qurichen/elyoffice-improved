2026-10-25。用户要求结合Microsoft Office痛点和GitHub扩展项目改进Ely结构、
框架和底层代码。来源、优先级、适用边界及后续方向见
[调查与架构说明](office-pain-points-architecture.md)。本轮采用原创实现，
没有复制外部项目代码或加载Office插件。

## 根因与结构调整

`LokView::run_at/run_all_at` 会传入读取时的 `Doc`，但旧 `Worker::run_all`
只在带编号参数时执行 `EXPECT`；选区写入等无编号命令可在状态变化后执行。
视图未核对句柄属于哪份文档；`SHOW_SHEET` 也没有推进操作上下文修订。

客户端和视图命令入口已分别提取到各自的 `commands.rs`，生命周期、画布与
调度职责分开，涉及的代码文件保持500行内。
严格批次入口先验证全部参数，再检查一次来源修订，随后依次执行；普通
即时输入继续按当前选区执行。视图核对worker会话和文档ID，拒绝其他文档
的句柄。工作表切换推进上下文修订，不作为视图文档编辑计数。

表格合并在读选区时取得同一worker锁内的来源 `Doc`，对话框保留它，保留/
移动按钮通过严格路径执行。选区或工作表已变时拒绝旧决定，使用已有的
中英文“文档已改变，请重试”错误路径；不自动改用新选区。

完整应用回归首先发现文字属性面板无条件用 `run_at` 发送即时命令，连续修改
格式、段距和纸张会因前序命令改变状态而被拒绝。现按现有命令描述判断：
编号引用继续严格检查，其余即时操作按当前选区排队。复用已有快速段距和
页面等集成测试，没有放宽共用保护或等待条件。

备注命令显式带原始幻灯片编号，单纯翻页不应丢失原页备注。命令元数据默认
为选区目标，严格批次有任何选区命令时用新增 `EXPECT_AT=37` 核对完整修订。
只有 `notes.set` 声明为文档目标，沿用 `EXPECT`：worker分别记录完整修订和
最近非 `SHOW_SHEET` 输入的修订；读取之后只有该翻页请求时允许写回原页。
其他已计数输入、内容或页序修改仍拒绝，未来修订也拒绝；`TURN` 没有被豁免。
`Doc` 编码与 `REVISION` 返回格式保持原样。

没有新增C++补丁、依赖或第三方扩展运行时。新增IPC标签要求客户端和工作
进程共同更新；旧worker未知请求时报错，不回退到无检查执行。仍沿用原有
72补丁内核。严格批次不是原子事务，运行中的命令
失败可能留下先前已成功的步骤，不宣称自动回滚。

最终清单 `E:/ElyOfficeBuild/qa-round17/artifacts.json` 核对27对C/E源码、
12个不同路径的制品、2065份本轮原始文件及全部72补丁；本轮范围外原文件
未变。原index SHA-256仍为
`35A149422418AA5EB4725BD66E21CB43EAA9572AF4F1F1C1E9E5A4EBBE780FE3`，
原120份暂存内容保持原样。最终只有6份本轮新增的未忽略文件：两个命令模块、
四项保护测试文件、两份文档和独立审查报告；未重建或改变SAL内核二进制。

## 限制与保护

命令有效性以worker已处理的请求修订为界，不能据此宣称覆盖引擎内部所有
异步事件、外部进程写文件或第三方脚本。持久区域绑定、完整SDK、扩展权限、
统一事务撤销和批量单帧IPC留待后续。复杂文档视觉、更多DPI、系统输入法、
多日使用、打印和安装升级仍未完成一般验收。

回归使用合成文件和隔离资料目录，不碰真实文档、系统设置或剪贴板；不
发布、提交、推送或替换安装版。保留原暂存/index、已有修复和72补丁。
