## 已实施的六处修改

| 项目 | 原问题 | 修改及边界 |
| --- | --- | --- |
| Windows默认打开文件 | `cmd /C start`会解释路径中的环境变量和命令字符 | 改为直接调用ShellExecuteExW，传入原样UTF-16路径，不启用环境展开；缺失/NUL路径在启动前报错，系统失败返回错误。COM初始化按成功次数配对，不更改文件关联。 |
| 附件文件名 | 共用库将名称直接join到目录，允许绝对路径或`../`越界 | 写入前限定单个普通文件名；Windows另拒绝ADS、保留设备名和尾部点/空格。保留中文、空格、特殊字符和碰撞另存。当前UI生成固定附件名，未发现现有UI可利用输入链。 |
| OLE宏风险扫描 | 排他循环上界漏掉最后一个完整128字节项 | 扫描全部完整项，忽略不足128字节的尾段，短输入不panic。只修复已有扫描策略的边界，不宣称实现完整OLE验证器。 |
| worker日志转接 | `read_until`对无换行长输出无上限，未知输出每行写一次日志 | 每行最多保留64KiB；超限后丢弃整行并继续排空到换行，后面的正常错误仍可读取。未知输出最终仅写数量汇总，正文不进入日志。 |
| 启动日志裁剪 | 仅保留尾段却先读入整个历史日志 | 从同一文件句柄取得长度，定位到尾段，仅读取半个日志预算，仍从完整行开始保留。读取期间文件缩短不会按旧长度切片panic。 |
| 文档事件快照 | 克隆整个Events后立即丢掉一次性字段 | 显式只复制快照需要保留的字段；未消费事件仍按原规则合并，空闲快照不重放一次性状态。没有宣称整套Office提速某个百分比。 |
