# 第26轮：ElyDoc选区翻译与可选模型连接

日期：2026-10-28。状态：已收尾，独立R1 PASS，限下述功能与验收范围。

## 功能与操作

在ElyDoc选中文字，打开“语言 → 翻译选中文字…”。对话框先展示选区快照；
启用翻译、填写完整Chat Completions API地址与模型名后，主动选择译为英文
或简体中文。结果只预览和复制，不插入、替换或保存文档，不执行模型工具。
选区最多16 KiB，响应正文最多1 MiB，最终译文最多64 KiB；失败不自动重试。

默认关闭。“保存连接”保存下次使用的开关、地址、模型和是否用密钥；配置文件
位于当前profile的`ely-doc/translation.json`，通过已有Store原子写入，保留其他
字段。读取损坏时明示错误并禁用保存和发送，不用空配置覆盖原件。

“使用API密钥”默认关闭，本地无鉴权服务无需访问凭据库。打开后可填写新密钥，
或留空使用此地址已存密钥；保存连接才将新密钥存入系统凭据库，另有忘记入口。
凭据按规范化profile路径和完整地址散列隔离；地址改变、保存或忘记成功后清空
密钥输入，避免将A服务的残留输入发送给B服务。设置文件不含密钥、选区或译文。

HTTP只允许回环IP，示例完整地址为
`http://127.0.0.1:11434/v1/chat/completions`；其余端点必须HTTPS。
拒绝URL内账号密码、查询、片段以及重定向，不使用代理或自动探测模型。
回环地址不等于离线推理：本地服务可以转发至云端，界面明确说明发送内容、
地址和可能收费；用户须自行配置真正的本地模型或远程服务。

阻塞HTTP和凭据调用在专用后台线程执行，通过oneshot返回界面。单面板不重复
发送；HTTP全局60秒、连接10秒上限。关闭立即设置取消标记，开始、传输返回、
结果接收和复制都拒绝已关闭面板，旧关闭回调不会关闭后来打开的其他对话框。
已发出的请求不能撤回，可能在后台结束。只接收一份完整assistant文字；拒绝、
截断、空内容、工具/函数响应和格式错误均失败，不将部分文字称为成功译文。

接口依据：[Chat Completions官方参考](https://developers.openai.com/api/reference/resources/chat)、
[Ollama兼容接口](https://docs.ollama.com/api/openai-compatibility)。使用该协议不代表
所有兼容服务、模型或参数已验收；未使用用户真实API密钥或产生付费模型请求。
