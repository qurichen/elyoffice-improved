## 问题与修复

上游整合已通过 `0067` 提供 `.uno:SelectedRange` 的 `filled` 计数，
但应用的 `Book::merge` 仍读 `selection_text` 并拆分文字数单元格。
空范围可能没有可读取的选中文字，因而无法完成合并；有一个可见值和一个
显示为空的公式时，文字计数只有1，原版会跳过多内容确认。

改为读取真实选区的 `filled`。0或1格有内容时直接合并，超过1格先确认；
多个不连续选区明确提示只能选择一个范围；查询或解析失败继续显示错误。
移除旧文字计数器，原厘米尺寸边界测试保留。

没有新增C++补丁、依赖或界面组件，也未改变合并对话框的保留/移动语义。
多行单格样例在旧版已能通过，只计作回归保护，不称为新修复。
