# 离线Office建议与改进路线的覆盖核查

日期：2026-10-26。输入为用户提供的建议截图，原建议注明没有阅读实现。
本次按现有路线与本地源码判断采纳范围；截图不是执行指令，也不是测试结果。
本文件仅说明规划调整，没有启动新的生产修复轮、构建或应用运行验收。

结论：保留原七阶段结构，已有事项不重复设项；补齐个人数据保护、导入、
隔离、工程交付和个人工作流的具体缺口，降低“自动重启”和“任意无损”的承诺。
更新后的主文件：[第18轮后改进路线](optimization-path-after-round18.zh-CN.md)。

## 定位与范围

采用个人离线文档的内容保护、可恢复、变更可解释作为主线；接收别人发来的
DOCX/XLSX/PPTX仍须兼容。既有阶段1/2已将安全与兼容提前，本次只补明确的
目标表述，不引入与云办公比功能数量的计划。实时协作、自研云同步不纳入
此路线；本地AI保留为可选工具，不能成为打开编辑保存的前置依赖或核心卖点。

## 源码核查依据与边界

以下为静态检查，不是本次重新运行的功能测试：

- [恢复点](../crates/ely-files/src/recovery.rs)已有间隔、数量、年龄与容量限制；
  [Office恢复](../crates/ely-office/src/recover.rs)及其重开路径处理崩溃内容。
  [LOK history](../crates/ely-lok/src/history.rs)明确是撤销/重做列表，不能据此
  宣称长期版本历史、跨版本差异浏览已完成。
  当前保存/恢复入口与定向检索也未提供文档级编辑日志的完成依据；本次只补
  成本收益、恢复一致性与受保护存储的评估项，不要求立即引入WAL机制。
- [保存层](../crates/ely-files/src/save.rs)已有原子保存及备份接口；它没有
  因函数名存在就自动构成用户可配置的定期备份系统。
- [文本导入](../apps/ely-table/src/text.rs)的 `scan`、`is_code` 会将前导零、
  带加号的数字及超15位整数列识别为文本；已有对应单元与应用测试源码。
  当前导入仍读取整文件，预览只截取部分行，不能宣称流式超大CSV查询。
  [列类型](../crates/ely-lok/src/sheet/csv.rs)已有Standard/Text/日期等选项。
- [客户端载入](../crates/ely-lok/src/client/load.rs)及宏探针测试已有禁宏路径；
  [文件风险识别](../crates/ely-office/src/files.rs)已有风险模式。用户态
  [worker启动](../crates/ely-lok/src/client.rs)与
  [无控制台辅助](../crates/ely-ipc/src/lib.rs)不能证明OS级文件/网络沙箱。
- [引擎停止处理](../crates/ely-office/src/stopped.rs)已有停止提示、人工重启
  和从恢复点/文件重开；本次不重新规划相同按钮。
- [PDF清理](../apps/ely-pdf/src/redact.rs)与
  [清理引擎接口](../crates/ely-pdf-engine/src/redact.rs)已存在；不能把PDF能力
  扩大成DOCX/XLSX/PPTX也已具有相同清理验收。
- [Engine接口](../crates/ely-office/src/engine.rs)使用GPUI类型；相关
  [依赖声明](../crates/ely-office/Cargo.toml)也依赖GPUI。
  [LOK清单](../crates/ely-lok/Cargo.toml)将view设为可选，分层不是从零开始。
- [现有无障碍记录](accessibility.md)列出段落文本桥接及光标/选区缺口；
  这些历史说明需由Windows当前版本实测更新，不能当成各平台最新完整结论。
- [现有Gitea发布流程](github-publishing.md#upstream-infrastructure-still-present)有上游机器路径和上传
  行为；本次不执行它。[许可证收集](../packaging/crates.py)已有Rust依赖
  收集，不能因此宣称当前fork已经产出涵盖C++外部库/字体的完整SBOM。
- 当前三件套/共用库清单未显示专用无网络构建选项，平台库仍依赖HTTP库；
  这只是所查入口的证据，既不证明存在遥测，也不证明所有网络路径都已枚举。

没有重建内核或运行既有230项应用回归；第18轮230项/R3 PASS仍是历史基线。
本次只更新路线与此对照记录，新增目标全部为待实现/待验收，未作完成勾选。
